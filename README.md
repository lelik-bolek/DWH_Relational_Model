# Проект: Нормализация реляционной модели (0НФ → 3НФ)

## Цель проекта
Показать процесс нормализации данных на примере онлайн-курсов: от исходной неструктурированной таблицы (0НФ) до полностью нормализованной модели в 3НФ с выделением справочников и фактовой таблицы.

## Структура проекта
- 0NF: исходные данные, все атрибуты объединены в одном поле.
- 1NF: атомарные атрибуты, определён первичный ключ.
- 2NF: устранены частичные зависимости, выделены справочники студентов и курсов.
- 3NF: устранены транзитивные зависимости, добавлены справочники городов, преподавателей и платежей, фактовая таблица содержит только ссылки и дату заказа.

## Используемые технологии
- PostgreSQL (SQL-скрипты для создания таблиц и загрузки данных)
- DBeaver (визуализация схемы)
- CSV (для исходных данных)
```
DWH_Relational_Model/
│
├── README.md                  # Общее описание проекта
├── Rules_of_Normalization.md  # Правила нормализации 1-3 НФ
│
├── 0NF/
│   ├── data.csv               # Исходные данные для 0НФ
│   ├── 0NF.sql                # Создание и вставка данных в 0НФ
│   └── Description_0NF.md     # Описание структуры данных 0НФ
│
├── 1NF/
│   ├── 1NF.sql                # Создание и вставка данных в 1НФ
│   └── Description_1NF.md     # Описание структуры данных 1НФ
│
├── 2NF/
│   ├── 2NF.sql                # Создание и вставка данных в 2НФ
│   └── Description_2NF.md     # Описание структуры данных 2НФ
│
└── 3NF/
    ├── 3NF.sql                # Создание и вставка данных в 3НФ
    └── Description_3NF.md     # Описание структуры данных 3НФ
```
