# Проект: Нормализация реляционной модели и SCD2 (0НФ → 3НФ_SCD2)

## Цель проекта
Показать процесс нормализации данных на примере онлайн-курсов: от исходной неструктурированной таблицы (0НФ) до полностью нормализованной модели в 3НФ с выделением справочников и фактовой таблицы, включая поддержку историчности данных (SCD2) для справочников и измерений.

## Основные задачи
1. Преобразование данных через нормальные формы:
   - 0НФ → 1НФ: атомарные атрибуты, определён первичный ключ.
   - 1НФ → 2НФ: устранены частичные зависимости, выделены справочники студентов и курсов.
   - 2НФ → 3НФ: устранены транзитивные зависимости, добавлены справочники городов, преподавателей и платежей.
2. Добавление историчности (SCD2) в справочники и измерения:
   - students → student_3nf_scd2
   - cities → cities_3nf_scd2
   - teachers → teachers_3nf_scd2
   - courses → courses_3nf_scd2
3. Фактовая таблица orders_3nf_fact связывает все измерения через surrogate key.
